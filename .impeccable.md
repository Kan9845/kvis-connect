## Design Tokens

### Separator Variables (globals.css)
Use these CSS variables for all borders/separators. Never use `border-foreground/N` or hardcoded oklch colors for separators.

| Token | Purpose | Light | Dark |
|---|---|---|---|
| `--kvis-rule` | Row dividers, list items | `oklch(90% 0.007 294)` | `oklch(22% 0.01 294)` |
| `--kvis-border` | Card borders, standard sections | `oklch(76% 0.009 294)` | `oklch(40% 0.014 294)` |
| `--sep-strong` | Page header underlines | `oklch(38% 0.010 294)` | `oklch(60% 0.010 294)` |
| `--sep-input` | Input field borders | `oklch(65% 0.008 294)` | `oklch(48% 0.012 294)` |
| `--sep-input-focus` | Focused input borders | `oklch(20% 0.012 294)` | `oklch(82% 0.012 294)` |

**Tailwind classes:** `border-[var(--kvis-rule)]`, `border-[var(--kvis-border)]`, `border-[var(--sep-strong)]`, `border-[var(--sep-input)]`

**Separator component:** Use shadcn `<Separator>` for standalone horizontal/vertical dividers (e.g., "or" dividers in auth). Use border classes for container edges.

### Spacing Tokens (tailwind.config.ts)
Semantic spacing scale for `gap-*`, `p-*`, `m-*`, etc.

| Token | Value | Usage |
|---|---|---|
| `xs` | 4px | micro spacing, tight icon gaps |
| `sm` | 8px | small spacing within components |
| `md` | 16px | default component spacing |
| `lg` | 24px | spacing between components |
| `xl` | 40px | generous section spacing |
| `2xl` | 64px | large inter-section gaps |
| `3xl` | 96px | page-level top/bottom padding |

**Example:** `gap-md` instead of `gap-4`, `gap-lg` instead of `gap-6`.

## Typography Standards

Reference: Navbar.tsx is the source of truth.

### Type Scale (Tailwind classes only — no arbitrary px sizes)
- `text-xs` (12px) — fine print, captions only
- `text-sm` (14px) — **baseline for all bento card content**: country names, percentages, labels, nav links
- `text-base` (16px) — emphasized body, card subtitles
- `text-lg` (18px) — card headings, section labels
- `text-xl` — hero numbers, big stats only
- `text-2xl` — step counters, display numerals (e.g. `01`, `02`)

### Weights
- `font-medium` — nav links, body text, country names
- `font-semibold` — emphasized labels, card section headers
- `font-bold` — numbers, percentages, key data points
- `font-extrabold` / `font-black` — hero stats only (count-up numbers)

### Colors (Tailwind gray scale + brand overrides)
- Primary text: `text-gray-900`
- Secondary text: `text-gray-600`
- Muted/caption: `text-gray-400`
- Brand accent (purple): inline `style={{ color: P.purple }}` or `text-[oklch(44%_0.26_294)]`

### Rules
- NEVER use arbitrary font sizes like `text-[11px]`, `text-[9px]`, `fontSize: 11`. Use the scale above.
- NEVER use `fontSize` in inline style. Always use Tailwind text classes.
- Use `tabular-nums` on all numeric/percentage values.

## Design Context

### Users
Thai science high school (KVIS) alumni — mostly aged 18–35, studying or working globally in STEM, finance, and creative fields. They visit to explore who's where in the world, read each other's experiences, and feel connected to the KVIS network. Context: casual desktop browsing, high curiosity, proud of the school identity.

### Brand Personality
Ambitious · Precise · Warm

KVIS is a prestigious Thai science school with a duck mascot. The alumni network should feel like a place where smart, accomplished people gather — proud of their roots, global in outlook.

### Aesthetic Direction
Light background ("The Bulletin" editorial feel), with an Apple-style bento grid on the landing page second section.
Brand colors: purple `oklch(44% 0.26 294)` (from "VIS" in logo), green `oklch(40% 0.16 148)` (from "K" in logo).
Font in use: Be Vietnam Pro (not in reject list — keep).
Anti-reference: anything that looks like a generic SaaS dashboard, cookie-cutter card grids, or AI slop.

### Design Principles
1. Every card must earn its space — real data, real density, no filler
2. Lists over grids when the content is sequential or ranked
3. Color as signal, not decoration — purple/green should carry meaning
4. Typography hierarchy over visual chrome — weight and size do the work
5. No banned patterns: no side-stripe borders, no gradient text, no glassmorphism
